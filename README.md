# Portfolio - Aidan Roche

Projet de site web vitrine réalisé dans le cadre du cours de HTML / CSS à Ynov Sophia.

## Description

Le site est composé de deux pages :
- index.html : page principale contenant ma présentation, mes compétences et mes projets.
- contact.html : page permettant de me contacter par email ou via mes réseaux.

## Structure du projet

- index.html : page d'accueil
- contact.html : page de contact
- style.css : feuille de style unique (thème Nuit)
- images/ : dossier contenant les images et logos du site

## Lancer le site

Il suffit d'ouvrir le fichier index.html dans un navigateur web.
